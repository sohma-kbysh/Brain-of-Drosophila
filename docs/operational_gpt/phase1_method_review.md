# Phase 1後の計画の手法点検

> 2026-09-12の最新の優先順位は[資源生成・操作・効率の実行計画](nonclassical_resource_execution_plan.md)を参照。以下は1A追加確認・1D設計時の点検記録であり、形式的な条件の未確立を理由に現在の資源評価を停止する指示ではない。歴史的記述にあるshadowの除外方針も更新されている。現在はshadowを有効資源の候補に含め、隠れた古典記憶の費用と有用性を測る。

結論：数値安定性を確認してから予測圧縮を測る順序は妥当。ただし「予測の十分性」「GPTとしての妥当性」「計算資源」を別々の主張にする必要がある。今回実施するのは、固定条件での1A追加確認と、通過後の1D有限予測pilotである。[実行前仕様](phase1_next_protocol.md)にデータ分割・選択・判定基準を固定した。

| 点検対象 | 判断と採用した対応 |
|---|---|
| 3.12ポイントという前回値 | 観測された差ではなく信頼上限。前回の最大推定差は1.185ポイントだった。追加データを別実験として取得し、同等性幅を変更しない |
| dtを半分にすれば正しいか | 保証しない。入力近似・イベント時刻を含めた確率の比較を行い、連続時間極限とは区別する |
| 独立seedか、同じ入力軌道か | 今回の目標は前者で検査できる分布上の安定性。同じseedだけでは、異なるdtで同じ連続Poisson軌道を共有したことにならない |
| 未測定の未来をSVDで予測する案 | SVDだけでは効果を特定できない。短い列から入力ごとの更新を推定し、長い列では更新を合成する |
| 未知の準備の状態取得 | 評価準備にも短い未来テストによるanchor測定が必要。その費用を記録し、測定不要のオンライン予測とは言わない |
| 評価の独立性 | 履歴を学習・検証・評価に分割。検証でモデル選択し、最終評価の予測を保存してからラベルを取得する |
| 同じ平均確率なら同じ状態か | 有限標本の近似一致を厳密な操作的同値としない。1Aの主張は全混合についてのaffine予測不足に限定する |
| 低rankならGPTか | 確率範囲、許容状態集合、効果集合、更新の閉性が別に必要。今回のモデルは有限の予測仮説として評価し、大域的GPTとは認定しない |
| RTCを推定表から認定できるか | 同じ低rank表を最小因子分解して相互識別性を得ても循環的。既知toyの親監査と、未確立のLIF親RTCを区別する |
| 次元と計算能力が相関すれば新しいか | それだけでは既存の容量・rank関係と区別できない。同じ次元・入力・読出し・測定予算で、幾何が追加の予測力を持つかを後続で検査する |

Brian2の公式文書は、PoissonGroupの各dtでの発火判定と、積分・閾値・シナプス・リセットの実行順序を明記している。従ってODEの`exact`更新指定だけを根拠に全シミュレーションを厳密と呼ぶことはできない。[入力仕様](https://brian2.readthedocs.io/en/stable/user/input.html)、[実行順序](https://brian2.readthedocs.io/en/stable/user/running.html)

未来予測を状態として使う構成はPSRの先行研究に接続する。今回のデータは入力履歴によって準備された集団を対象とし、途中の発火観測で条件付けない。したがって一般のaction–observation履歴に基づくfilterを実装したという主張は避ける。観測を条件に更新する場合には、観測確率による規格化を含む更新が必要になる。[Littman, Sutton & Singh (2001)](https://proceedings.neurips.cc/paper/2001/file/1e4d36177d71bbb3558e43af9577d70e-Paper.pdf)

相対的完全性は、状態と効果が互いを識別するという親に対する条件である。新しい準備や効果を追加して推定値が安定することは有用な監査になるが、それだけで未知の親に対する完全性の証明にはならない。この研究で古典親のshadowを生物の非古典資源と呼ばない方針は維持する。[Schmid et al.](https://arxiv.org/abs/2409.13024)

後続の容量測定ではDambreらのinformation processing capacityを参考にできる。ただし、線形読出しでの容量の上限と、その上限を達成する条件を区別する必要がある。fading memory、状態変数の線形独立性、課題の基底などの仮定を確認せず、LIFの操作的次元がそのまま容量に等しいとは置かない。今回の短いreset実験から定常入力下のfading memoryも確立していない。[Dambre et al. (2012)](https://www.nature.com/articles/srep00514)

実connectomeへの移行条件は、少なくとも神経モデル上での予測圧縮の評価と、その使用時間範囲での数値安定性が整うことである。1Aの最大32 msの検査は、1Dの最大92 msの全履歴に自動的に適用されない。1Dを実施しても、今回の数値はまずdt=0.05 msの離散モデルの結果として扱う。
