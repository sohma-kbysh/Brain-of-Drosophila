# 生物コネクトーム計算の操作的幾何：Phase 0 研究メモ

**結論は、問いは条件付きで数学的に成立するが、任意の粗視化から得た非埋込性だけでは生物計算の説明にならない、ということである。** 微視的に古典的な回路に対し、生物学的根拠のある準備・介入・測定制約を先に定め、許可された未来の確率が等しい準備を同一視する。その状態と効果の対を再構成し、単体埋込みと計算課題との関係を調べる。全未来の有限次元性、生物学的制限の妥当性、計算への追加説明力はいずれも未証明である。

**Phase 1への更新：** 主課題は「計算に十分な操作的状態の圧縮と、状態–効果幾何の説明力」、単体埋込みは副次検査とした。relative tomographyを親モデルに対して監査する1A–1Cの合成実験を実装・実行した。以下はPhase 0の研究メモとして保持し、現状は [Phase 1仕様](phase1_protocol.md)・[結果](phase1_results.md) を参照する。

## 1. 対象となる系は何か

指定した神経部分回路または CNS を一つの古典的な入出力装置として扱う。微視状態 $\lambda\in\Lambda$ は電位、シナプス駆動、不応期、遅延事象などを含み、古典 kernel $K_a(d\lambda'\mid\lambda)$ が発展を定める。MaleCNS は将来の解剖学的基盤で、局所動力学や生理状態そのものではない。現行コードの Shiu 様 LIF はモデル転用であり、MaleCNS 動力学の実験的検証ではない。[^1]

## 2. 操作的状態とは何か

準備 $P$ の作る微視分布を $\mu_P$ とする。$P\simeq P'$ は**全ての許可未来テスト** $q$ について $p(q\mid P)=p(q\mid P')$ が成立すること、$\omega_P=[P]$ はその同値類である。$\omega$ と $\lambda$ は別の対象である。即時発火率の一致では未来同値性を保証しない。未来集合が介入の前置に閉じれば $T_a[P]=[aP]$ が定義でき、有限 horizon では通常 $\Omega^{H+1}\to\Omega^H$ だけが保証される。[形式化と証明](01_operational_formalism.md)

## 3. GPT トモグラフィーは何を再構成するか

準備と未来効果の確率表 $D$ を、状態行列と効果行列の積 $D=SE$ に因子分解する。有限標本では真の確率と rank を不確実性込みで推定する。$S\to SG,E\to G^{-1}E$ で統計が変わらないため、座標の図だけには一意の物理的意味がない。[^2]

再構成するのは指定操作の確率 pairing であり、一般には親 fragment の **shadow** である。全脳の微視空間、全許容測定、全未来の有限 dimension を特定したことにはならない。状態と効果の両方に対する relative tomography の条件が重要である。[^3]

## 4. 単体埋込みとは何か

同じ古典単体 $\Delta_L$ に状態を、対応する古典応答へ効果を写し、非負性、規格化、混合、全指定等式、$e(\omega)$ を同時に保てるかという問題である。適切な有限 ontic・凸性等の条件で、prepare–measure の一般化非文脈モデルの存在に対応する。[^4] 状態図が非単体でも、弱い効果と組み合わせれば埋込み可能である。変換全体の非文脈性には追加の遷移・合成条件を要する。[正例と反例](03_classicality_and_contextuality.md)

## 5. どの意味で「非古典的」になり得るか

正しく指定した制限操作理論が、その操作的同値性を尊重する非文脈表現を持たない、という意味に限定する。古典二ビット装置でも、各試行に片方のビットだけを終端読出しし、parity を読めない制限を置くと、異なる parity 混合が同値になる。その商には非文脈モデルがない。しかし元の古典装置は依然としてその全統計を生成する。

**主要な既知制約：任意の多面体 GPT は、古典単体理論の fragment の shadow として実現できる。** 一方、元の線形関係を保った単純な操作集合の制限は埋込みを保存する。[^3] この区別を消して「古典性を破った」と言うことはできない。

## 6. どの意味では確実に違うか

古典 simulator の再記述は、ハエの量子性、ニューロンの量子ビット性、古典物理の破れ、量子計算 supremacy の証拠にならない。非可換な古典遷移は簡単に構成でき、順序依存も文脈性の十分条件ではない。計算資源・計算上の優位には課題、比較クラス、費用、readout 制約が必要である。[逐次計算と no-go](04_sequence_computation.md)

## 7. reservoir computing とどこが違うか

connectome を recurrent reservoir として使うことは既存研究である。[^5] 将来観測の予測ベクトルを状態にすることも PSR に先行がある。[^6] 追加する問いは、準備混合・未来同値性・測定制限を明示した状態–効果 fragment の埋込み性や操作的識別性が、通常の reservoir/PSR 指標を超えて性能や介入効果を説明するかである。そうならなければ単なる再記述という批判を受け入れる。

## 8. 現時点で最も強く擁護できる新規性は何か

**実測生物コネクトーム、生物学的制約のある動力学、prepare–transform–measure interface、データ駆動の状態–効果再構成、単体埋込み検査、統制された計算容量比較の組合せ**が候補である。神経ネットワークを GPT で扱う直接隣接研究も既にあるため、その導入自体を初とは言えない。[^7] 調査した一次文献群では六要素をまとめて実施した直接一致例を確認していないが、不存在や世界初を証明したものではない。[文献比較](06_prior_work.md)・[主張別判定](07_novelty_matrix.md) を参照する。

## 9. 何が動機を反証するか

生物学的に正当化した制約では非埋込性が生じず、得られた幾何量も通常の reservoir 指標以上に計算を説明しないなら、「特別な操作的幾何が計算を支える」という強い動機を棄却する。MaleCNS と matched random reservoirs の幾何・容量が事前閾値内で同等なら、MaleCNS 特殊性も棄却する。非埋込性だけが恣意的な情報隠蔽に依存する場合も、生物計算の説明に採用しない。非有意だけは無差の証明ではなく、同等性区間と検出力が必要である。[仮説](08_hypotheses.md)・[red team](10_failure_modes.md)

## 10. Phase 0 の直後に行う最小のシミュレーションは何か

合成二ニューロン再帰 LIF 一系で、4 種の二文字入力履歴と3種の未来テスト（即時・待機後・追加刺激後の発火有無）から、4×3 の確率表を独立 reset で得る。各セル200試行、計2,400試行の固定 pilot とし、unit を含む真の表の rank が2を超える証拠があるかを調べる。即時確率一個が全混合に対する未来の affine な十分状態かを反証可能にする試験で、MaleCNS 特殊性や文脈性はまだ検定しない。回路・時間・入力・統計判定の詳細は [実験仕様 §6](09_future_experiment_spec.md) に固定した。

## Phase 1 の判定

理論の一貫性、$\lambda/\omega$ の区別、単体埋込みの定義、反証可能性、既存 reservoir との差分、gauge と統計条件、負の中止結果を文書化できた。**上記の合成 pilot のみ条件付き Go** とする。生物学的 interface の根拠、有限標本校正、十分な未来予測の確認前に、MaleCNS の文脈性・計算資源実証へ進むことは推奨しない。
