# GPT-like挙動と有効資源の推定を主評価にする

> **実行状況（2026-09-13）：** [1E・初回2Aの結果](resource_experiment_v1_results.md)を保存した。29,328,000試行で8・16ニューロンの静的候補特性を確認したが、指定した操作は未達。次は保持・操作可能性を含める設計方式の比較へ進む。[実行計画](nonclassical_resource_execution_plan.md)の最終目的は、GPTの視点を使って資源を生成・操作できるか、生成・利用費用が有利かを判定することである。

2026-09-12のユーザー指示を反映した方針。主目的は、制限された準備・入力・観測を通じて現れるGPT-likeな挙動を特徴付け、それをどの程度の計算資源として利用できるかを推定することに置く。厳密なGPT公理への整合性、完全な凸集合・錐の同定、親に対するrelative tomographic completenessの証明は、資源評価を開始するための必須条件としない。

これ以前の実行前仕様は過去実験の記録として保持する。既存の成功・失敗や判定基準を事後的に変更する趣旨ではない。

## 何をGPT-likeな挙動として測るか

有限精度・有限時間・指定interfaceにおいて、状態、効果、入力による更新を用いた操作的記述がどこまで有用かを測る。候補となる観測量は、履歴依存、短い未来テストによる状態圧縮、順序依存、準備間の識別可能性、混合への応答、観測制限やノイズによる幾何・性能の変化である。

形式をモデルに組み込んだだけで創発の証拠とはせず、未使用の準備・入力で予測できるか、回路条件を変えたとき挙動と性能がどう変わるかを測る。一つの順序効果だけで全てのGPT-like構造を認定する規約にもせず、観測量ごとの結果を報告する。古典的な親から創発する有効な挙動自体を研究対象に含める。

## resource estimationの主指標

| 軸 | 主な出力 |
|---|---|
| 利用できる能力 | 主課題は遅延選択によるビット読出しと、その準備状態を引き継ぐ操作。記憶・XOR・IPCは補助指標 |
| 予算に対する有用性 | 同じ測定・入力・読出し予算での成績差、許容誤差を満たす観測予算の候補上限 |
| 操作的な複雑さ | 誤差・horizon別の予測座標数、識別可能性、順序効果の大きさ |
| 利用コスト | 初期校正、準備・測定回数、状態推定、更新・読出し、モデルと状態の記憶量 |
| 頑健性 | 標本数、観測ノイズ、入力の揺らぎ、回路変更、時間刻みに対する性能変化 |

単一の普遍的なresource値を仮定せず、まず性能と費用の関係を報告する。例えば固定比較モデルbに対し

$$\Delta_b(B,H)=L_b(B,H)-L_{\mathrm{op}}(B,H)$$

を用い、同じアクセス予算Bでの正の改善を調べる。この差は指定比較モデルへの改善であり、全古典計算の最適値との差ではない。予算を掃引して得た合格点も、全方式に対する最小必要予算とは区別する。

記憶・非線形課題の容量測定はDambreらの枠組みを参考にする。実際の有限データでの課題成績と、追加仮定の下での容量定理は分けて扱う。[Information Processing Capacity of Dynamical Systems](https://backoffice.biblio.ugent.be/download/2972574/2972575)

## これからの優先順位

4座標モデルを固定した測定予算の比較は[探索的profile](resource_profile_results.md)として完了した。**1E** の資源ベンチマーク・費用台帳を実装し、2Aの初回共通ランダム探索対照と独立確認を[実施済み](resource_experiment_v1_results.md)。保持時間と操作を含める設計の比較、2Bの実測結線モデル、独立した効率確認が残る。[実行計画](nonclassical_resource_execution_plan.md)の基準・対照・探索上限を採用する。

GPTによる設計と通常のtask-only／PSRによる設計を、同じ総試行予算で比較する。2ビット古典shadowを必須対照とし、非古典的に見える特性の生成と実用効率をそれぞれ判定する。時間刻みへの感度は資源推定の誤差要因として並行して検査する。未確認の形式的条件を全て解消するまで資源評価を停止する運用は採らない。

RTC、単体埋込み、指定ノイズに対するrobustness等は補助診断として保存する。shadowがどのinterfaceから生じたかは記録するが、shadowであることだけを理由に有用な有効資源の評価を中止しない。[Schmid et al.](https://arxiv.org/abs/2409.13024)

## 実施済み：既存データからの最初の集計

以下は[結果を保存済み](resource_profile_results.md)の探索的な再解析の仕様である。新しい神経試行は行わず、保存済み1Dデータを使った。モデル・次元・ridgeは再選択していない。

1. 学習表にある同じ2入力の順序 `01` と `10` の終端確率差を測る。28×15の元確率表全体を同時95%で覆う区間から、全28履歴の差区間を導く。入力時間と1の個数は同じだが、入力時刻は異なる。その差を順序依存として報告する。
2. 新しい準備一個あたりの測定総数Bを200、2,000、10,000に揃える。操作的モデルは7テストにほぼ等分し、即時モデルは1テストへ全てを割り当てる。余りは事前に固定されたcore列順で配る。保存outcomeの先頭を利用し、予算間は入れ子で独立反復ではない。
3. 元の操作的モデルの予算70,000も参考行として残す。こちらには同予算の即時モデルの新データがないので、費用を揃えた比較とはしない。
4. 元の64評価確率の同時95%領域から、各予算での誤差とモデル間損失差の区間を求める。同じ領域で全ての固定予測を覆う。anchorの再測定による平均性能を保証する区間ではない。
5. 4座標・2種類のアフィン更新・1効果について、float64を選んだ場合の数値payloadと演算回数を見積もる。PythonやJSONの実占有量、シミュレータ、物理回路、エネルギーの費用とは区別する。

この再解析は、能力と費用を結び付ける最初の資源プロファイルである。既存の独立評価実験とは区別し、新しい確認実験として数えない。
