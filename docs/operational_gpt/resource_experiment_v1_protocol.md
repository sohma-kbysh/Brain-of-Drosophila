# 1E・初回2A：資源生成と操作の共通対照実験

2026-09-13。探索と確認の実行前仕様。[親計画](nonclassical_resource_execution_plan.md)の1Eを実装し、2Aの最初の共通ランダム探索対照を行う。[設定](../../configs/operational_resource_experiment_v1.json)を実行時にhash付きで保存する。

## 今回答えること

2・8・16ニューロンの古典的な合成LIF回路で、単発の遅延ビット読出しについて高い成功率と小さなparity漏れを同時に生成できるか。固定された刺激操作を加えて、状態を引き継ぐ反転・交換ができるか。許された観測を両出力へ開くとparityが読めるか。生成探索と利用でどれだけのアクセス・活動・制御が必要か。

これは実測結線・生体の実験でも、GPTによる設計と通常設計の比較実験でもない。後者の比較を名目だけで実装せず、まず全方式に必要な生成・操作の共通対照を測る。親計画の45 runの3方式比較を完了したとは報告しない。

## 動力学と物理操作

膜電位をrestからthresholdまでの差7 mVで規格化し、dv/dt=(-v+g+I)/20 ms、dg/dt=-g/5 ms、threshold 1、reset 0、refractory 2.2 ms、delay 1.8 msとする。古典的な区分定数電流下のsubthreshold flowを解析的に更新し、イベントはdt=0.1 msの格子上に置く。これは以前のPoisson準備の2-neuron実験とは別の合成モデルである。

二つの同数のpoolを設ける。同じpool内の他ニューロンからの結合は総gainになるよう正規化し、対応する他poolのニューロンへ0.05 gainの結合を置く。2ニューロンではpool内結合はない。全結合は興奮性で、autapseはない。この設計を解剖学的な生物回路とは呼ばない。

4入力ラベルごとに二つのpoolへ12 msの定電流を与え、2 ms待つ。各F/W操作は二相各5 msのpool別の符号付き電流。各操作は準備ラベルを参照せず、途中で内部状態を置換しない。読出しは両poolへ5 ms、2.5単位の共通電流を与え、選択されたpoolの半数以上が一度以上発火したかを1ビットとして返す。偶数poolではちょうど半数も1とする。

trialごと・ニューロンごとの独立な一様±15%の電流gain揺らぎと、20 Hzの独立な背景イベント（gに0.2を加算）を使う。背景イベントの判定確率は各dtでrate×dt。揺らぎは各trial中では固定する。各trialはrestから始まり、resetは1操作として計上する。resetの実機実装時間・エネルギーは未測定である。

query別の条件を均等に割り付ける。コードは準備・操作の発展にqueryを参照せず、終端のmonitor選択にのみ使用する。生体で遅延乱数queryを発生させる装置を構成したとはしない。joint対照では同じtrialから二つのpool出力を取得し、2読出しビットとして計上する。単一monitor制限の物理的な強制装置・費用は未実装であるため、今回のshadowは明示したinterfaceに条件付ける。

## 探索と選択

各サイズに5つの独立した探索seedを割り当てる。各runで以下を実施する。

1. 準備電流8個とgainについて64候補を評価する。候補0は低0・高1.6の直接符号化、gain 2。候補1–31はこの符号化の低・高電流とラベル別電流を揺らがせ、候補32–63は各ラベルの電流を独立に一様生成する。gainは0–8。各8 cellを200試行で評価する。
2. 成功率S−2δの上位4候補を独立2,000試行/cellで再評価し、一つの準備とgainを選ぶ。δはこの二つの読出しだけのparity差。
3. 選んだ準備を固定し、F/Wの電流8個を64候補から探索する。候補0は全て0、残りは−3–3の一様乱数。各候補についてFとWの計16 cellを200試行で測る。評価値はmin(S_F,S_W)−2 max(δ_F,δ_W)。
4. 上位4候補を独立2,000試行/cellで再評価する。最終gateを選ぶ。

各runの総試行数は102,400+64,000+204,800+128,000=499,200。15 runで7,488,000試行。失敗候補・probeも含む。上限は親計画のrunあたり500,000を超えない。

各サイズから、検証データのmin(S,S_F,S_W)−2 max(δ,δ_F,δ_W)が最大のrunを一つ選ぶ。全候補・選択規則・選択結果を保存し、確認前にselection lockを作る。新しいモデル・最適化方式・探索範囲を同じcampaignへ追加しない。

## 独立確認

選んだ3装置について、F/Wの長さ0–4の全31列、何も刺激しない同じ長さ1–4の待機、静的なjoint読出し、予め選んだ5列のdt=0.05/0.025 msを、それぞれ20,000試行/cellで測る。待機の結果を同じ経過時間の目標準備として使い、操作の応答誤差を測る。

通常の単一出力確率280 cell×3装置、dt比較80 cell×3装置、jointの4カテゴリー確率16 cell×3装置、計1,128確率を同時95%のBonferroni Clopper–Pearson区間で覆う。これから派生する全てのS、parity差、指定操作誤差と数値差を同じ領域で評価する。

通常確認16,800,000試行、dt監査4,800,000試行、joint監査240,000試行、合計21,840,000試行。探索と合わせ29,328,000試行を予定する。jointの二つのビットは1準備から取得し、2準備と数えない。確認の試行数を途中の有意性に応じて増減しない。

初期判定は親計画通り、静的Sの下限0.80、δの上限0.02、長さ4の平均S下限0.80かつ各列下限0.77、操作応答誤差上限0.05。静的interfaceと操作を含めたinterfaceを別に判定する。厳密な操作的同値性を仮定せず、これらの合格を厳密な非文脈性否定とはしない。

dt監査は指定した5列についての感度検査であり、全31列の数値安定性を保証しない。結果はまず指定の離散LIFモデルに対するものとして扱う。
