# Phase 1追加実験：手法点検と実行前仕様

本仕様と設定を新しいデータの取得前に固定する。既存run1/run2は探索・校正の履歴として保存し、追加結果と合算して初回成功とは報告しない。本段階は合成二ニューロン系のみである。

## 点検結果と今回の決定

先の提案は方向として妥当だが、次を明確にする必要がある。

1. `method="exact"` はLIFの区間内ODE更新についての指定である。発火閾値、遅延、入力、測定窓を含む連続時間系全体の厳密解を意味しない。Brian2のPoissonGroupは各dtで `rand() < rate*dt` を用いる。独立seedでdtを変える今回の検査は、この入力近似も含む終端確率の比較であり、同じPoisson軌道に対する強収束・連続時間極限の証明ではない。[Brian2入力仕様](https://brian2.readthedocs.io/en/stable/user/input.html)、[実行順序・時計](https://brian2.readthedocs.io/en/stable/user/running.html)
2. 新しい未来テストの効果を一度も校正せずに、有限表のSVDだけからその確率を推定することはできない。今回は短い未来テストで入力ごとの状態更新を学習し、その合成によって長い未来列を予測する。準備は入力履歴で定まり、途中の発火観測による条件付けはしない。このため対象はopen-loopの集団予測状態であり、観測条件付きオンラインfilterの完成版ではない。[Littman, Sutton & Singh, Predictive Representations of State (2001)](https://proceedings.neurips.cc/paper/2001/file/1e4d36177d71bbb3558e43af9577d70e-Paper.pdf)
3. 低次元の予測モデルが得られても、完全なGPT、真の最小次元、相対的完全性、計算優位が得られたとは限らない。状態・効果を同じ低rank表から作って相互識別可能とするだけでは親へのRTC監査にならない。現段階ではLIF親のRTCを未確立とする。[Schmid et al.](https://arxiv.org/abs/2409.13024)
4. 準備ごとに反復して未来テストの確率を推定する費用を計上する。圧縮後の座標数だけを計算コストとしない。PCA座標の角度や距離を物理的な幾何不変量と解釈しない。

今回の順序は **1A追加確認 → 通過した場合に1Dの有限予測モデルの検証** とする。1B/1Cを繰り返して成功例を増やすことはしない。計算容量ベンチマークと実connectomeの取得は今回の実行対象外である。

## 1A追加確認

元の4準備×3未来を維持し、dt=0.1/0.05/0.025 msの各セルに新しい独立10万試行を取得する。2万試行を上限とする5バッチを異なるseedで集計し、同一seedを複数バッチに再利用しない。各バッチで初期化するのは独立試行であり、準備から未来への境界では初期化しない。

最終Nだけを一度判定する。36確率のBonferroni Clopper–Pearson信頼箱を同時95%で構成する。この同じ箱から全3組のdt比較を導くため、比較のための追加のunion boundは不要である。全セル・全比較の差区間が±0.03内なら指定の確率安定性を通過とする。各dtでunit付きrank≥3の区間証拠も要求する。3ポイントは既存の工学的許容幅であり、任意の後続計算課題に十分な精度だと保証しない。

通過しなければ1Dの新データ取得は開始せず、差の場所と区間を記録する。不合格後にseed、刺激、許容幅を変えて再試行しない。3点の一致も連続時間極限の証明ではない。

## 1D：有限の操作的予測モデル

### データと分割

- 学習準備：長さ2/3/4の全二値入力履歴、計28個。
- 検証・最終評価準備：長さ5の全32履歴を固定seedで並べ替え、16個ずつに分割する。学習・検証・評価で履歴は重複しない。
- 状態推定用テスト（anchors）：長さ0/1/2の全入力列Q、計7個。終端の節点2の2 ms発火有無は既存実験と同じ。
- 学習データ：各学習準備に長さ0～3の全15未来列、各1万試行。これにQと全てのuQ（u=0,1）が含まれる。
- 検証・評価データ：各準備のQに各1万試行、別試行の長い未来 `0000,0101,1010,1111` に各2万試行。

長い4入力列の確率は学習表に含めない。検証ラベルはモデル選択に使うため、それらに関して未学習と主張しない。最終評価ラベルは、選択モデルと予測を保存した後に取得する。最終評価準備のanchor測定は許すが、これは新しい準備をtomographyするための費用である。反復測定なしの未知履歴推論とは称さない。等しい連結入力列が別の準備・未来分割に現れても、試行やラベルを流用しない。

### モデル

学習準備のQ表をX、列平均をm、中心化SVDの右方向をV_kとし、

$$z(h)=[1,(X(h)-m)V_k]$$

を使う。k=1,…,7は規格化された状態の候補座標数で、unitを含む線形次元はk+1である。Vとmは学習データだけで決める。各uについて、実測したuQ表からz(hu)を作り、z(h)A_u≈z(hu)をridge回帰する。unit列は常に(1,0,…,0)へ固定し、interceptは正則化しない。目的関数は平均二乗誤差+λ×係数二乗和、λ∈{10^-6,10^-4,10^-2}を事前固定する。

即時効果eは同じSVDの復号から得て、長い未来u1…u4を

$$\widehat p(o\mid h,u_1\cdots u_4)=z(h)A_{u_1}A_{u_2}A_{u_3}A_{u_4}e$$

で予測する。入力順序を逆転させない。これらは平均分布に対する線形更新であって、観測で条件付ける一般PSRの更新則とは区別する。

これは有限標本の説明変数にも誤差がある回帰であり、無偏推定や一致性をこのpilotで保証しない。独立の評価データで、その誤差も含めた予測性能を測る。k<7は7個のanchor座標からの圧縮であり、微視的な電位・シナプス変数・遅延queueの座標数との比較ではない。

比較対象は、即時発火確率一個を状態として同様に更新するモデル（λだけ選択）と、入力履歴の末尾2binごとの平均即時確率を使うモデルである。後者は**入力履歴**であり、発火履歴ではない。長い未来後の末尾2binから予測する。この簡易比較で全ての履歴モデルに対する優越とは主張しない。

### 選択・評価・停止

検証準備のanchorから予測を作った後、独立の検証ラベルに対するBrier損失差を比較する。候補間損失差の同時Hoeffding半径は既存v2と同じ導出を用いる。操作的モデル群と即時モデル群にはそれぞれ選択alpha/2を配分する。検証予測が[0,1]を外れる候補は除外する（丸め許容10^-10、clipして隠さない）。経験的最良より明らかに悪いと示されない候補のうち最小k、同じkなら最大λを採用する。これは候補集合内の選択規約で、最小十分次元の証明ではない。

選択モデルを固定し、評価anchorから全モデルの予測を保存・hash化してから64個の最終評価確率のラベルを取得する。64確率を同時95%の二項信頼箱で覆い、各固定予測の確率RMSE・最大誤差の上下界、および二モデルの期待Brier損失差の上下界を箱上で厳密に計算する。確率RMSEは観測ラベルへのBrier scoreと同一ではないので別々に記録する。予測を条件にした今回の評価であり、新しいanchor再測定や未検査の全履歴への保証ではない。

候補全ての誤差曲線を保存するが、評価後にモデルを選び直さない。選択モデルが、評価予測の確率範囲、確率RMSE上限0.03、最大誤差上限0.05、k<7、即時モデルより期待Brier損失が小さいという区間証拠、を全て満たせば有限予測圧縮pilotのgateを通す。0.03/0.05はこのpilotの事前精度目標であり、全未来十分性の定義ではない。

範囲外予測、更新誤差の累積、非改善、未判定を全て保存する。成功しても、指定した準備と4未来テストの凸混合への限定的な検査であり、更新が未知の状態を物理的状態空間内へ写すこと、効果集合の完全性、一般GPT再構成を証明しない。

## 実装の検証

既知の有限古典制御系を使い、正確な確率で学習した更新が未学習の長い列を再現すること、入力順序、unitの保存、凸混合、過小次元の負例を検査する。新しいLIF実装は既存の短いプロトコルを同一seedで再現すること、無入力で沈黙すること、長い入力列の分割位置を変えても結果が同じことを検査する。

設定・ソースsnapshot・hash・環境版・seed・バッチ計数・元outcome・モデル・予測固定記録・図・報告を新規出力先に保存する。既存結果を上書きしない。1Aと1Dの各信頼領域はそれぞれ95%であり、全研究を束ねた95%保証とはしない。
